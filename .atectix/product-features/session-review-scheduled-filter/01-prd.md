# 会话复盘：按发起方式分类，默认只看由人发起的会话

状态：2026-10-05 Jack 确认了原则、默认隐藏、插话算人参与、快照照采页面过滤；把视图从两档改为「定时任务 / 由人发起 / 其他」三分类，默认只展示「由人发起」。同日实现完成并在本机生效，记录见 [02-implementation-plan.md](02-implementation-plan.md)。

## 用户需要

feishu-autocook 以 Paseo 定时任务的形式每半小时左右跑一次，每次 run 都是一个独立的 Claude 会话。复盘页把它们和 Jack 自己的会话混在一起（2026-10-05 15:30 的快照）：

| 范围 | 会话总数 | 其中定时任务 run |
|---|---|---|
| 今天 | 15 | 11 |
| 10-03 | 41 | 38 |
| 最近 7 天 | 126 | 67 |

后果：时间线被每半小时一条的短会话刷屏；「会话」「最大并行」「总活跃」等汇总被机器 run 撑大；决策点列表混入 run 的内容。Jack 想看的是自己，以及自己参与过的 agent，那一天干了什么。

同一个项目目录下也有 Jack 自己的会话（最近 7 天有 3 个 feishu-autocook 目录下的设计讨论，各有 2 到 14 条他发的消息），所以不能按项目或目录整体排除。

## 原则

复盘的对象是人参与过的工作。每个会话按「谁发起、有没有人说话」分成三类，互不重叠，每个会话恰好属于一类：

- 由人发起：有人发过消息的会话。自己开的会话都在这里；定时任务或别的 agent 发起、但人插过话的会话也算这里，因为人一开口就是人参与的工作。
- 定时任务：Paseo 定时任务发起，从头到尾只有启动提示、没有人说过话。
- 其他：既不是定时任务发起、也没有任何人说过话的会话。目前能遇到的是别的 agent 委派出来的会话，以及开了没说话的空会话。

识别依据是记录，不是内容：Paseo 定时任务和 agent 委派发起的会话自带记录，按记录识别，不按项目路径、关键词或内容分类。将来新增的定时任务（比如 health 项目的）不需要任何配置就自动适用；其他被采集节点上的会话同样按该节点自己的记录识别，节点上不需要配置任何东西。

## 范围

- 复盘页新增视图切换，四档：「由人发起」（默认）「定时任务」「其他」「全部」，每档带当前范围内的数量，例如「由人发起 4 · 定时任务 11 · 其他 0 · 全部 15」。隐藏因此不是静默的。
- 定时任务按任务名称分列数量，例如「定时任务：feishu-autocook 11」。
- 会话的展开行和消息详情带来源标签：定时任务发起的带「定时 · <任务名>」，无论它现在属于哪一类；agent 委派的带「agent 委派」；没人说话的空会话带「无人发言」。由人发起且自己开的会话不加标签，和现在一样。
- 汇总数字（会话、最大并行、总活跃、等你、决策点、无法解析）和决策点列表始终跟随当前视图。
- 快照照常采集全部会话；切换视图在本机完成，不重新连接节点，不丢任何数据，随时可以回看 run 本身（例如 10-05 中午 26 分钟内连跑 7 次的那种情况）。

非目标：

- 不提供按项目、目录或关键词的排除规则，不做基于内容的自动分类。
- 不把同一个定时任务的多次 run 合并成一行；如有需要作为后续需求。
- 不改 feishu-autocook 本身，不删除已采集的数据，不新增插件设置项。

## 页面行为

1. 侧栏复盘页和工作区面板打开时都是「由人发起」视图。切换视图后，切换日期、项目、节点都保持该视图，并和现有筛选一样在布局切换重挂载时保留。
2. 范围内没有定时任务和其他会话、且当前是默认视图时，不显示视图切换，页面与现在完全一致。只要有可隐藏的会话，或当前视图不是默认，就显示切换，保证随时能切回来。
3. 「由人发起」视图：定时任务和其他会话不出现在时间线、决策点和汇总里；插过话的定时任务会话照常显示并带「定时 · <任务名>」标签。
4. 「定时任务」「其他」「全部」视图：只显示对应类别，标签规则同上，消息照常可查看。
5. 定时任务已被删除、只剩 run 记录时，标签显示任务 id，不报错。
6. 每个节点最多 200 个可见会话的限制按当前视图里可见的会话计算，被隐藏的会话不占名额。

## 验收标准

1. 今天范围的默认视图不含任何定时任务 run（起草时为 15 个会话中的 11 个），汇总随之变化，切换控件写明四档数量和「feishu-autocook 11」；切到「定时任务」只剩 run，切到「全部」全部出现，run 的展开行带「定时 · feishu-autocook」标签。
2. 项目选 feishu-autocook、默认视图：不含任何 run。Jack 在该目录里的会话是在 Jack-Env 工作区开的，按既有的归属规则属于 Jack-Env 项目，在那个项目下可见，不受本功能影响。
3. 合成用例：Jack 插过话的定时任务会话在默认视图可见并带标签；agent 委派且没人插话的会话归「其他」；没有任何记录但在同一目录的会话归「由人发起」、无标签；没人说话的空会话归「其他」。
4. 其他节点的会话用同样方式识别，节点上无需配置；没有定时任务的节点页面不变。
5. 升级后已有快照自动重新采集，不需要手动清缓存。
6. 窄屏与宽屏下切换控件可用；决策点列表、详情弹窗和「立即更新」在各视图下都正常。
