# Paseo 公共 Skills 管理

状态：产品设计已获用户确认，包括首版范围、交互和失败处理。2026-09-30 按用户要求增加多来源登记与移除、节点状态共享记录。2026-10-01 按用户要求取消分发预览与确认，节点操作改为「扫描」和一键「同步」。

## 用户需要与结果

用户在 Paseo 中查看公共技能、各节点的一致性和差异，并直接检查上游更新、更新控制中心快照、分发到选定节点。操作不依赖 agent 在对话中逐步执行；agent 与 GUI 使用同一份公共来源、快照和管理规则。

## 已确认的基础

- 控制中心统一维护公共技能，按用户指令向节点分发。
- 公共来源是控制中心登记的来源列表，支持 Git 仓库和 well-known 发现索引。当前为 `Tom-0727/atectix-ai-engineering-skills` 的 `main` 分支 `skills/` 下全部技能，以及飞书官方发现索引中的 `lark-suite`（官方原版）。
- 节点公共技能保持一致，节点专属技能保留；Codex 与 Claude 默认共用一套。
- 首版 GUI 支持查看和操作，包括检查仓库更新、查看差异和同步到节点，复用现有同步逻辑。
- 插件实现独立于 Paseo 源码和安装文件，代码位于本仓库并随 Git 管理；使用 Paseo 官方扩展机制接入。
- 实际 Web 入口为 `https://paseo.atectix.com`。用户连接并选择控制中心节点后，可看到插件提供的“公共 Skills”页面。

## 首版范围

提供 Paseo 中的“公共 Skills”入口，主页面包含统计概览、来源、技能与节点状态；技能库更新的差异确认和任务结果由操作卡片承接。来源在页面中登记和移除；公共技能增删改通过来源的变化进入更新流程。

首版不包含在线编辑技能正文、为 Codex/Claude 分别启停技能、修改节点专属技能、定时同步或双向合并。

## 页面与交互

### 统计概览

仅展示公共技能数量、来源数量、节点数量、一致性统计和更新操作。未检查的节点不计作已一致。来源跟随每个技能展示，主页面不展示 commit、分支、目录或“快照”术语。

- **检查更新**：读取上游，在原区域显示检查状态；检查本身不改变技能库或节点。
- **更新技能库**：仅发现更新时显示入口，点击后在卡片中查看新增、修改和移除，确认后采用预览版本；只更新控制中心。检测到控制中心尚未处理的本地修改时，保留内容并说明冲突。
- **同步当前快照**：可以独立发起，无需重新拉取上游。

### 来源

列出每个来源的名称（Git 为仓库名，发现索引为发布域名）、类型、纳入范围和技能库中的技能数；点击名称展开地址、分支和目录。

- **添加来源**：填写类型、ID、地址，Git 可选分支和目录，可限定技能名。提交时实际拉取一次并检查与已有技能重名，通过后登记。
- **移除来源**：二次确认，并列出将移出的技能。
- 两者只改来源列表；技能在下一次检查并确认更新后进入或移出技能库，再同步时到达或撤离节点。

### 技能与节点状态

桌面以“技能 × 节点”的状态表展示，紧凑屏幕按节点查看技能列表。每个技能旁展示来源。点击技能打开独立详情卡片，阅读说明、正文和各节点状态；关闭后回到原列表位置，不在列表下方插入详情。

展示与当前快照一致、缺失、待更新、本地修改、链接异常、待撤回等状态；无法读取的节点显示不可达或检查失败，不把未知状态算作一致。展示检查时间，支持手动扫描。状态取自控制中心最近一次检查记录，agent 或页面执行的扫描、同步都会更新；技能库更新后显示“待重新检查”，不沿用旧结论。

节点专属技能单独标识，仅供查看。节点是否可达以控制中心对该节点的实际检查结果为准。

### 扫描与同步

节点区域只有两个操作，都作用于所选节点；默认选中全部已登记节点，允许改为部分节点。

- **扫描**：只读，检查所选节点与当前技能库的一致状态。
- **同步**：一次点击直接完成，没有预览和确认。每个节点先检查：已一致的直接结束，不传输；不一致的传输一次、写入并校验，包括新增、更新、撤回已从公共来源移除的受管公共技能和调整链接。节点专属技能保持原样。

进度在“节点与技能”区域原位按节点展示检查、传输、写入、校验以及完成或失败。仅在执行后校验通过时标为成功。结束后可打开任务结果，查看每个节点实际写入、移除的内容和冲突；不设置独立的底部任务区。

### 失败、重试与离开页面

- 某节点离线或有冲突时，其余正常节点继续执行；汇总明确显示成功、冲突和不可达，不能将部分成功显示为全量完成。
- 同一节点有内容冲突时，阻止该节点整次修改，展示冲突原因，不提供静默强制覆盖。
- 用户可以手动重试失败节点；重试前重新检查当前内容。
- 关闭页面不取消正在执行的任务，重新进入可查看当前任务。重复点击不会启动相同的重复写操作。
- 控制中心服务重启或任务结果不明确时，重新盘点节点，按实际内容显示状态，不根据旧进度假定成功。

## 验收标准

1. 页面读取现有公共来源和快照，并能展示已登记节点的公共技能一致性；状态不是固定的演示数据。
2. 检查更新显示真实差异，检查过程不会改动启用中的公共快照或节点技能。
3. 确认更新快照后，仅控制中心版本变化；用户能继续明确选择何时分发、分发到哪些节点。
4. 同步一次点击完成，采用当前技能库版本；已一致的节点不传输，执行后重新校验技能内容和适用的链接，保留节点专属技能。
5. 上游移除的受管公共技能在同步时撤回，并列在任务结果中；其他技能不受影响。
6. 有冲突或不可达节点时，页面呈现部分完成及具体原因，并能单独重试失败节点。
7. 离开后返回页面能查看仍在运行的任务；执行结果不明确时，可刷新获得当前实际状态。
8. GUI 与 agent 对同一来源和节点的检查、更新、冲突判断采用一致的规则。
